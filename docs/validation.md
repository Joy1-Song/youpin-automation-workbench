# 发布前检查

## 范围

本次以既有个人项目为基础整理公开作品集副本，未变更实盘目录、账号配置或挂单，也未把个人简历、订单、库存、日志或模拟器文件带入仓库。

## 已修复的问题

1. **损坏队列被视为空队列**：原逻辑在 JSON 损坏或结构错误时返回空队列，可能重新生成指令。现在报错停止并保留原文件，测试覆盖截断 JSON、错误根类型、错误列表和无效条目。
2. **队列直接覆盖写入**：改为同目录临时文件写入、flush/fsync、原子替换。模拟替换失败时验证旧文件内容保持不变。
3. **数量下限绕过硬上限**：当策略最小数量被配置为大于 7 时拒绝计算，避免通用分配器重新抬高最大值。
4. **示例配置含自动提交开关**：公开示例关闭自动处理、提交、撤单和通知；预算核对启用未成交敞口。
5. **出货接口文档过时**：修正为每品类目标在售数量，而非每轮新增数量，更新实际配置字段。

## 验证内容

- 既有测试：中英文贴纸匹配、空品类补单、已有正确在售保留、超额下架、重新定价、低于毛涨幅阈值撤单，以及假客户端执行顺序。
- 新增测试：离线完整流程、最低价 10 类筛选、预算不足、数量上限、午夜日切、资产去重、已成交与未成交敞口、库存查询失败、队列损坏及写入失败、过时指令取消、缺失成本/CD 跳过、双阈值预警和安全默认值。
- 本地 pytest：**34 项通过**（Windows，Python 3.13.9）。本地环境隔离了全局 pytest 插件，临时目录放在工作区，避免执行沙箱的系统临时目录权限问题。
- CI 配置：Windows / Ubuntu，Python 3.11 / 3.12；真实结果以 GitHub Actions 为准，不将配置存在视为测试通过。

`python demo.py` 和 `python scripts/check_publication.py` 用于独立检查演示与发布内容。脱敏脚本支持 `--compare-env <本地凭据文件>`，只输出匹配的文件名，不输出敏感值；该选项不在 CI 中运行。
