# 简历与工程证据

## 推荐项目表述

**饰品自动求购与库存管理桌面工作台 | Python、Tkinter、ADB、pytest | 个人项目，AI 辅助开发**

- 围绕个人求购、库存和价格提醒需求构建桌面工具，通过后台线程与消息队列更新 UI，将策略计算、预算风控、平台适配和通知拆为独立模块。
- 设计可插拔的选品、定价、数量分配与出货接口，实现按品类维护目标在售数量、部分成交挂单重建及购入成本辅助补全。
- 使用 Decimal、每日预算窗口和未成交敞口校验控制计划；为执行队列增加原子落盘和损坏时停止机制，补充离线演示、回归测试及跨平台 CI。

根据简历空间保留 2-3 条。不要填写未经证实的收益、吞吐量、节省时间或稳定性百分比，也不要把此项目称为 RAG / 大模型项目。
