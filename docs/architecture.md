# 架构与模块边界

## 当前分层

| 层 | 文件 | 职责与边界 |
| --- | --- | --- |
| 表现层 | `youpin_desktop_app.py`、`youpin_desktop_*` | UI、配置入口、工作线程与状态展示；不应新增策略公式 |
| 调度与编排 | `youpin_auto_runner.py`、`youpin_major_bidder.py` | 周期执行、风控先行、计划构建与结果汇总 |
| 策略层 | `strategies/`、`youpin_builtin_strategies.py`、`youpin_strategy_sdk.py` | 选品、价格和数量计算；返回动作而非直接启动模拟器 |
| 风控与对账 | `youpin_risk_manager.py`、`youpin_order_reconciler.py`、`youpin_exit_manager.py` | 预算校验、过期/部分成交挂单处理、出货规则 |
| 适配层 | `youpin_api.py`、`youpin_market_data.py`、`youpin_emulator_executor.py` | 平台字段、网络调用和 APP 页面操作 |
| 执行桥 | `youpin_execution_bridge.py` | JSON 指令队列、状态变化、活跃指令去重 |
| 辅助服务 | `youpin_buy_price_fill.py`、`youpin_daily_report.py`、`youpin_price_alert.py`、`youpin_cs_update_alert.py` | 成本关联、日报、价格和更新通知 |

共享模型使用 dataclass，金额使用 Decimal。策略通过 `plugin:<文件名>` 加载，桌面通过 `DESKTOP_PROFILE` 获取展示配置。插件只面向可信本地 Python 代码，没有沙箱。

## 一轮求购

1. 读取配置和本地状态，检查自动化开关与更新保护。
2. 获取候选、当前求购与库存，交由策略选择、定价和分配数量。
3. 形成需要撤销的挂单与新计划，计算当日成交和计划后敞口。
4. 在显式启用实盘和对应执行开关后执行；新建指令可转交模拟器队列。
5. 记录执行状态和下次计划时间；通知模块按独立周期检查。

离线演示只复用计算与本地队列部分，不冒充真实 API 成功，也不模拟网络传输的可靠性。

## 状态与恢复

执行指令包含稳定 ID、状态与状态历史。相同的活跃新建指令会复用；失效的待处理指令可取消。队列使用同目录临时文件、flush/fsync 和原子替换，避免中途退出留下半个 JSON。无法解析的队列直接报错并保留原文件，不再默认为空队列。

这不是 exactly-once 事务系统。远端成功但本地写回失败时仍需人工/远端订单对账，原子写文件也不能解决两个进程同时读改写的竞争。当前应单实例运行，不要将状态目录共享给多个执行器。

## 出货对账

按品类汇总可交易库存和既有在售项，排除自己的报价后确定市场参考。以参考卖价减 0.1 元为候选报价，核对每个资产的记录成本，再决定保留、下架、重新上架或补足空缺。目标是每类最多 3 张在售，不是每轮新增 3 张。无外部报价时会参考自己的已有报价；缺少可靠价格时不创建新动作。

## 仍需改进

- `youpin_major_bidder.py` 和桌面入口仍然承担较多职责；可逐步提取应用服务，避免通知模块反向依赖大入口。
- JSON 存储没有事务和多进程锁；下一步可用 SQLite 的唯一约束、事务与执行租约管理指令。
- 成交统计依赖库存、成本数据与本地账本，不等同平台清算账本；存在同步延迟、缺失成本和资产变更风险。
- 日切使用运行主机本地时间，尚未统一为显式业务时区和带时区时间戳。
- ADB 页面操作依赖第三方界面；需要录制脱敏页面样本建立 UI 回归集，当前没有真实 APP 的 CI 测试。
- 插件加载器没有沙箱，也未提供正式的类型协议/版本迁移约束。
- 当前 CI 验证核心离线行为，不覆盖完整桌面视觉、长期运行、多实例或实盘一致性。

这些边界是后续改进清单，不应在简历中表述为已实现的高可用、分布式或交易所级能力。
